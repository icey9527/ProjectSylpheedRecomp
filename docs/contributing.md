# 贡献说明

当前支持开发版输入与 Windows x64 Debug。提交前核对 [输入文件](game-inputs.md)，并说明修改解决的具体问题。

## 修改位置

- 宿主启动与配置位于 `src/app/`；游戏行为补丁按实际职责新增模块。
- 分析入口、函数边界和原生替换配置位于 `config/`。
- `generated/` 由 ReXGlue 管理。生成错误应修复配置或生成器，不能手改生成结果。
- SDK 修复应保留可重复应用的源码或补丁，并记录 SDK 版本。

## 验证

1. 修改前检查工作树，避免覆盖其他人的改动。
2. 分析配置变化后运行 `scripts/Codegen.ps1`，检查未解析调用、局部标签和指令警告。
3. C++ 或 CMake 变化后执行 configure/build；运行修复还需重测触发场景。
4. 分开记录代码生成、配置、编译链接、实际运行结果。缺少环境或输入时注明未验证项目。
5. 提交前运行 `git diff --check` 并审查差异。一个提交围绕一个问题，说明原因、验证和限制。

涉及游戏函数时记录 Xbox 地址、符号、对象归属和匹配证据。同地址的别名应保留；不能用相邻 MAP 地址猜函数长度，也不能把地址直接移植到其他镜像。

不要提交游戏镜像、MAP/PDB 原件、完整符号索引、生成代码、构建产物、凭据或个人机器路径。已发布的修改通过新提交修正，撤销可使用 `git revert`。
