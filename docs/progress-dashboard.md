# 本地实时进度面板

双击仓库根目录 `Start-Progress.bat`。使用已安装 Python 3.11+，不需要 pip、Node 或数据库。
脚本自动寻找 Python Launcher / python，启动本地服务器并打开系统默认浏览器。
按推荐外层布局使用时，也可以双击工作区根目录的本地 `打开进度面板.bat`。

启动窗口显示实际 URL，默认 `http://127.0.0.1:8765/`。保持窗口运行；Ctrl+C 停止服务器。
重复启动复用同一个工程的服务器；端口被其他应用或其他工作区占用时尝试后续 19 个端口。
只绑定 127.0.0.1。页面只读，不提供提交、推送或执行修复按钮。

## 数据如何更新

每 5 秒以及按“刷新”时重新读取，不缓存工程状态，不自动联网：

| 来源 | 内容 | 是否进 Git |
| --- | --- | --- |
| `progress/milestones.json` | 阶段、验收项、当前工作、下一步、版本分工 | 是 |
| 本地 Git | 最近 20 次提交、HEAD、分支、未提交更改、upstream 本机引用差异 | Git 自身记录 |
| 外层 `plans/*.md` | 最近 8 份计划，按文件修改时间排序 | 否 |
| 外层 `HANDOFF.md` | 最后 16,000 字符交接记录 | 否 |
| 里程碑中引用的证据路径 | 文件可读取情况、修改时间 | 依文件类型；日志/产物不上传 |

状态没有写死在 Python、HTML 或 JavaScript 中。Git 和计划直接读本机文件。
验收状态由维护者根据实际验证更新 JSON；程序不会把任意日志中的“成功”或产物存在直接判作游戏运行成功。
当前工作与下一步从 JSON 的 `current_task` / `next_tasks` 读取，计划正文从 Markdown 实时读取。
修改后无需重启；页面模板、JS/CSS 改动后重新加载网页。服务器 Python 改动则需要重启。

## 百分比的含义

百分比 = 有验收日期且全部证据路径可读取的 `done` 项数量 / 当前清单验收项总数。
所有项等权，阶段分别用同样规则计算。只表示**当前验收清单完成率**，不是工作量、可玩程度或时间预测。
新增验收项会改变分母。不从代码行数、文件大小、提交次数或勾选计划数量估算进度。

初始清单是 24 项，其中 8 项已验收，为 33.3%。首次游戏加载、菜单及实际游戏流程仍未验证。
若完成项没有验收日期、没有证据或任何证据文件缺失，显示“证据待核对”，不计入完成数。
文件存在只能确认验收记录的证据可读取；不重新执行构建或验证历史行为。
JSON 无效时暂停百分比计算并显示错误；断线时标明上次数据，避免误认为仍在更新。

## 每次维护需要更新什么

1. 任务前更新外层计划；更换工作重点时更新 `current_task` 和 `next_tasks`。
2. 做完并验证后，更新对应验收项的状态、`note`、`verified_at` 和证据路径，同时更新顶层 `updated_at` / `headline`。
3. 新出现的待完成工作必须加入清单或计划，注明实际限制。模块新增或范围变化需同步验收项。
4. 更新本地 HANDOFF，审查并提交脚本/状态/文档；推送后记录 SHA。Git 更改区会自动反映真实提交。

任务状态允许 `pending`、`in_progress`、`blocked`、`done`。`unverified` 是服务器计算出来的状态，不手写。
证据路径声明 `base` 为 `repo` 或 `workspace`，`path` 使用相对路径；不允许越出相应目录。
只记录说明、日期、路径，不能内嵌游戏源码、符号原件或日志全文。
试玩版不设日常构建里程碑，仅保留文档参考；不能为扩大完成数量添加无意义任务。

命令行也可使用：

```powershell
python scripts/progress_server.py --open
python scripts/progress_server.py --snapshot
python scripts/progress_server.py --port 0
python -m unittest discover -s tests -v
```

`--snapshot` 输出实时 JSON；`--port 0` 自动选择空闲端口。其他目录布局可通过 `--workspace` 指定外层目录。
页面不会执行计划、交接、Git 提交或日志里出现的命令，也不提供原文件下载/目录浏览。
计划正文及 Git 文本按普通文字显示。不同机器缺少本地证据时会显示待核对，而不会复制原机器的验收百分比。
