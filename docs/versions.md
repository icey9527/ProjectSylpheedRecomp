# 游戏版本、符号与运行阶段

用户说明当前 Xacalite_ScriptTeam.exe 是游戏开发/调试镜像，并非最终零售镜像。
这是用户提供的版本信息；镜像和 PDB 的 CodeView GUID/age 严格身份校验仍未完成。
目前保留该镜像为分析与运行准备基线，不切换输入或把零售文件覆盖到它的位置。

## 为什么先用有符号的开发版

MAP/PDB 已用于确认 44 个缺失函数入口、定位 17 个 catch funclet 边界问题，以及建立名称/地址/对象/生成位置索引。
这些是实际完成的用途。符号还能辅助后续检查调用关系、异常处理和数据结构，但本项目尚未读取完整类型/局部变量信息。

开发镜像可能含开发工具、诊断代码、特殊 API 或不同内容，不能因为有符号就保证它比零售版更容易运行。
必须优先确认与这份镜像对应的资源。零售资源是否兼容只能通过版本信息与实际加载验证判断。

用户已指定零售版资源和游戏行为为最终目标。零售版作为最终行为和内容的比较基准，
为它独立生成代码、保存输入 hash、manifest、索引和验证结果；不能沿用开发版的函数地址和补丁位置。
开发版符号可帮助理解相近函数，但跨版本关系需重新核对。两个版本的原始文件都保留本地。

“Xbox 游戏开发镜像”和“Windows 宿主 Debug/Release 编译配置”是两个维度。
把宿主编成 Release 只改变宿主优化/调试配置，不会把开发镜像变成零售游戏。

## 当前代码与维护方式（2026-10-01）

- 生成 C++：133 个文件，4,774,107 行，约 140 MB（十进制）；包含大量指令展开与注释。
- 识别的 sub_ADDRESS 定义：34,579 个，不等于原始业务函数数量。
- 手写 C++/头文件目前只有 src/app 中两个宿主骨架文件。
- MAP 34,638 个不同函数地址，其中 34,373 个能连接独立 sub_ADDRESS 定义；其他地址需区分辅助符号/内部块等。
- MAP 名字、可读名字、PDB 公共/模块匹配状态和生成位置存在本地符号索引；生成函数没有全部重命名或加原始名字注释。
- 789 条 MAP 记录未在当前读取的公共/PROC32/LABEL32 中找到同一位置，仍待核对。

维护从 `python scripts/symbols.py query <名字或地址>` 开始，记录镜像身份、地址、名字及证据，
再改手写代码、配置或可重复 SDK 补丁。Codegen/Build 在符号工具可用时刷新索引。
生成代码本身不提交、不手改，不需要人工重写几百万行或在运行验证前还原全部函数名字。

## 运行验收分阶段

1. **宿主启动**：Windows EXE 与 DLL 可加载。已编译，曾进入 SDK 的资源路径提示；不代表加载游戏。
2. **游戏镜像加载**：核对匹配资源、game_data_root、实际启动镜像路径、GPU 插件，做有日志和超时的首次加载检查。
3. **菜单/第一帧**：处理首次加载暴露的 API、内存、图形或异常问题；并行跟踪已知 30 条指令警告。
4. **实际可玩**：逐项验证输入、音频、任务、场景切换、存档和稳定性。

当前只知道未提供资源路径，没有实际游戏加载日志，因此不能可靠承诺进入菜单或稳定可玩的日期。
先取得匹配资源并做首次加载，按真实阻塞评估下一阶段工作。开发版身份与符号覆盖不能替代运行验收。

### 独立生成分析探测

试玩版与零售版均使用独立临时 manifest，未导入开发版 MAP/PDB、入口补充或 catch 边界配置。
SDK 实际退出码均为 1：各有 **22 条 UnresolvedCall，涉及 12 个不同目标地址**。
零售版约 31.6 秒、试玩版约 29.3 秒，停在分析验证阶段；没有生成完成、编译或运行成功结论。
这些只是分析器暴露的首批阻塞，不是完整缺陷数量，相同数量不代表代码相同。
试玩版中文输入路径的 init 首次失败；复制小镜像到本地 ASCII 探测路径后可进入分析。
原因尚未定位，不能据此归咎于游戏镜像。

开发版工程已修复入口与异常边界，并通过 Windows Debug 编译。试玩版主要省在资源，
XEX 和 image_size 接近零售版；本次没有证据证明先维护试玩版能明显省工。

### 基线选择与下一步

1. 开发版保留为符号参考与近期启动诊断基线。用它自己的资源，核对镜像虚拟路径、
   game_data_root、xenos 插件并做有日志和超时的加载检查；继续跟踪 float16_4 和符号身份问题。
2. 零售版为最终目标。另立 manifest、生成目录、索引和补丁，核实这 12 个目标的 PPC 入口，
   再生成、编译和使用零售资源加载。开发版名字可辅助理解，地址必须重新验证。
3. 试玩版保留为资源/行为对照，有具体测试收益再启用；当前不维护第三套正式宿主。

本轮未切换正式工程输入。若开发版被调试模块或资源接口阻塞，应依据加载日志调整优先级，
不因已有投入持续绕远路，也不按目录体积决定切换。
